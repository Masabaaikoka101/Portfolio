# 会話ログ記録スキル

このスキルは、Antigravityでの会話内容を `.knowledge/logs/` に記録します。

## 使用タイミング

- ユーザーが `/log-session` を呼び出した時
- 大きなタスクが完了し、notify_user を呼ぶ前（リマインドとして提案）

## 実行手順

### 1. 会話の要約を作成

以下の情報を整理してください：

```markdown
# セッションログ: [日付] - [メインタスクのタイトル]

## セッション概要
- **日時**: YYYY-MM-DD HH:MM
- **所要時間**: 約X分
- **主な目的**: [ユーザーが達成したかったこと]

## プロンプト履歴

会話で入力したプロンプト（原文）：

### 1. 最初のリクエスト
> [ユーザーの最初のリクエストをそのまま引用]

### 2. 追加のリクエスト（あれば）
> [追加のリクエストをそのまま引用]

### 3. ...（以降続く）

## 実行したタスク

### [タスク名1]
- [実施内容1]
- [実施内容2]

### [タスク名2]
- [実施内容1]

## 変更されたファイル
| ファイル | 変更種別 |
|---------|---------|
| `path/to/file.ts` | 新規作成 / 修正 / 削除 |

## 学び・インサイト
- [このセッションで得られた知見]
- [今後に活かせるポイント]

## 関連情報
- [参照したドキュメントやURL]

## 次のアクション（任意）
- [ ] [残タスクがあれば記載]
```

### 2. ファイルを保存

// turbo
```bash
# ログフォルダが存在しない場合は作成
mkdir -p .knowledge/logs
```

ファイル名の形式: `YYYY-MM-DD_[タスク名(kebab-case)].md`

例: `2026-01-17_tutorial-modal-refactor.md`

### 3. 保存完了を報告

ユーザーに以下を伝えてください：
- 保存したファイルパス
- 主な記録内容のサマリー

---

## リマインドモード

大きなタスク（task_boundary で複数ステップを経たもの）が完了し、notify_user を呼ぶ際に、以下のメッセージを追加してください：

```
💾 **セッションログの保存**
この会話をナレッジとして保存しますか？
`/log-session` と入力すると、今回の作業内容を `.knowledge/logs/` に記録できます。
```

---

## 注意事項

- 機密情報（APIキー、パスワード等）はログに含めないこと
- ファイル名は日本語を避け、英語のkebab-caseを使用
- 同じ日に複数セッションがある場合はサフィックスを追加（例: `_01`, `_02`）
